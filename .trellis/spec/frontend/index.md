# Frontend Development Guidelines

> Not applicable — reproxy is a Go CLI/server with no frontend.

---

This project has no UI layer: it is an HTTP reverse proxy binary (`cmd/reproxy`). The template files in this directory are unused scaffolding from `trellis init` (fullstack preset) and should NOT be filled — doing so would put aspirational content into specs that sub-agents auto-load.

**If a frontend is ever added** (e.g. a metrics dashboard): delete this note, fill the files below with real conventions from that codebase, and re-point the task jsonl manifests at them.
